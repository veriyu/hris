## Coding Standards

### General

- SOLID
- DRY
- KISS
- Clean Code

### Laravel

- Form Request validation
- Service layer
- Action classes
- Policies
- Resource API
- Queue when appropriate

### Database

- Foreign keys
- Indexes
- Transactions
- Soft Deletes when needed

### Security

- Authorization everywhere
- Input validation
- Prevent mass assignment
- Prevent N+1 queries
