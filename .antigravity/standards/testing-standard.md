# Testing Standard

## Required Coverage

Every module must include:

- Feature Test
- Authorization Test
- Validation Test

## Test Naming

Good:

it_can_create_employee()

it_rejects_duplicate_nik()

it_prevents_unauthorized_access()

## Required Scenarios

### Happy Path

Expected process succeeds.

### Validation

Invalid data rejected.

### Authorization

Permission enforced.

### Edge Cases

Unexpected input handled.

## Coverage Goal

Minimum 80%.
