Aku adalah seorang software engineer yang berfokus pada pengembangan aplikasi bisnis dan sistem operasional menggunakan Laravel dan Filament. Selain aktif sebagai developer, saya juga terlibat langsung sebagai volunteer bendahara koperasi, sehingga saya memiliki pemahaman nyata terhadap proses keuangan, transaksi anggota, simpanan, pinjaman, cash flow, hingga kebutuhan operasional organisasi dari sisi lapangan — bukan hanya dari sisi teknis.

Pengalaman tersebut membuat saya terbiasa membangun sistem yang tidak sekadar “fitur berjalan”, tetapi benar-benar mengikuti alur bisnis dan kebutuhan pengguna sehari-hari. Saya banyak mengembangkan aplikasi seperti:

* sistem koperasi,
* accounting & finance,
* HRMS,
* loan management,
* membership system,
* dan aplikasi operasional internal perusahaan.

Dalam pengembangan software, saya memiliki fokus kuat pada:

* business logic,
* data integrity,
* maintainable architecture,
* automation workflow,
* dan reporting system.

Tech stack utama saya:

* PHP 8+
* Laravel
* Filament Admin Panel
* MySQL
* REST API
* Queue & Scheduler
* Laravel Testing
* PDF & Reporting System

Saya juga mulai memperdalam area modern engineering seperti:

* React + Vite
* Docker
* CI/CD
* DevOps workflow
* scalable architecture
* distributed systems concept

Cara kerja saya cenderung analitis dan sistematis. Saya lebih nyaman membangun fondasi sistem yang rapi, scalable, dan sustainable dibanding membuat solusi cepat yang sulit dirawat di masa depan. Karena cukup dekat dengan proses bisnis dan operasional nyata, saya juga terbiasa menerjemahkan kebutuhan non-teknis menjadi sistem yang bisa digunakan secara praktis oleh user.

Selain development, saya aktif menggunakan AI-assisted engineering workflow untuk membantu:

* requirement breakdown,
* PRD drafting,
* sprint planning,
* issue decomposition,
* test generation,
* hingga architecture refinement.

Saya percaya software yang baik bukan hanya soal teknologi, tetapi bagaimana sistem tersebut benar-benar membantu operasional berjalan lebih efisien, transparan, dan dapat dipercaya.
